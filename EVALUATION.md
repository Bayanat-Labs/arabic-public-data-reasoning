# Evaluation protocol

Model input consists only of `question_ar` and the parsed `context` table, plus the answer contract. `code/model_input.py` implements that boundary. Gold answer, program, operation, evidence labels, template/family IDs and diagnostic metadata are not inputs. All split gold is public, so a public test is not evidence of contamination-free evaluation. Optional `question_en` is a controlled authored counterpart; evaluate English separately with the same source cells, not as a second independent dataset.

Predict one JSON object per line: `{"id":"...","answer":{"status":"ok","value":"...","unit":"..."},"evidence_ids":["..."]}`. Use a boolean for comparisons and ascending string-year arrays for ranks. Numeric values may be decimal strings; finite JSON numbers also normalize numerically. Booleans never normalize to numeric 0/1. Lookup requires exact displayed precision; derived numeric answers are rounded to six decimals, HALF_UP. Missing source cells are null; incompatible-unit outputs have null value and unit.

`python code/score.py --release . --predictions predictions.jsonl --split test --output score.json` reports answer, status, value, unit, reference-evidence micro precision/recall and strict joint. Strict joint requires exact answer and the exact set of reference evidence IDs, with no duplicate/nonexistent citations. Missing prediction IDs are wrong; duplicate or unknown/out-of-scope IDs fail the entire submission. Use only IDs for the selected split and scope. `--scope shared` or `--scope diagnostic` changes the expected submission IDs. Nonstandard JSON NaN/Infinity values fail parsing; string forms fail numeric correctness. Extra answer keys fail its exact schema.

Report the test shared-operator population (820 questions) separately from the second-highest-distinct-value structure diagnostic (113 questions). Include per-operator results and missing/incompatible status slices. Test has only DZA, EGY and SOM; validation has DJI, KWT and SAU. Do not report 933 unrelated independent samples: questions share cells, series and templates. Cluster uncertainty at economy or connected source-cell level; three test clusters are a severe limitation. A single aggregate score can hide lookup simplicity and rare abstention targets.

Source-cell references are a software program read set. Every displayed cell is evidence for its question, so citing all displayed cells passes the evidence criterion. This does not test distractor rejection, retrieval quality, minimal human proof or internal reasoning faithfulness. No explanations/chain-of-thought text is scored or required.

The supplied first-cell baseline reads the first visible cell and returns its recorded value without understanding the question. The symbolic baseline reads only the whitelisted input, identifies one of the declared controlled Arabic templates, and runs exact arithmetic; all template/operator forms, including the test diagnostic, are explicitly implemented. It is a programmed format ceiling, not a learned-model, unknown-template or production result. Neither baseline calls a model or uses a paid API.
